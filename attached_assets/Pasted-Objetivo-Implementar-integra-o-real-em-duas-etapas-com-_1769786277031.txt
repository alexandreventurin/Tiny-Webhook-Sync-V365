Objetivo: Implementar integração real em duas etapas, com segurança:
1) Usar token do Tiny A (Rejuderme) SOMENTE PARA GET para buscar detalhes completos do pedido.
2) Usar token do Tiny B (Muy Bela) para criar o pedido em B em "Dados Incompletos" (situacao=8).

Regras de segurança:
- NUNCA logar tokens.
- Feature flags:
  - ENABLE_FETCH_A=true/false (default true)
  - EXECUTE_TINY_B=true/false (default false)
- Allowlist opcional:
  - ALLOW_VENDA_IDS (ex: "30012,30013") -> se setado, só executa para esses IDs.
- Rate limit básico: não fazer mais de 1 GET por venda_id por X minutos (cache no DB).
- Se faltar dado essencial (endereço/itens), NÃO criar em B. Marcar job como failed com reason="missing_required_fields".

  - salvar venda_b_id em orders_map (external_key="A:<venda_id>")
