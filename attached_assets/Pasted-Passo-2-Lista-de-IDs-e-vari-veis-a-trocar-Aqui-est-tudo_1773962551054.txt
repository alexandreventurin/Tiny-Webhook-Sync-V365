Passo 3: Criar banco Supabase para C
Crie um novo projeto no Supabase
As tabelas são criadas automaticamente pela aplicação ao iniciar (o código em db.py faz CREATE TABLE IF NOT EXISTS)
Copie a connection string e coloque como DATABASE_URL no novo Repl
Popule a tabela products_map com os mapeamentos A → C
Popule a tabela feature_flags (pode copiar as mesmas flags)
Passo 4: Configurar OAuth e Webhooks
OAuth: No novo Repl, acesse /auth/a/start e /auth/b/start para conectar Tiny A e Tiny C
Webhooks no Tiny A: Configurar novos webhooks apontando para o novo Repl:
https://novo-repl.replit.app/webhooks/a/vendas
(os mesmos endpoints, mas no domínio do novo Repl)
Webhooks no Tiny C: Configurar:
https://novo-repl.replit.app/webhooks/b/vendas
https://novo-repl.replit.app/webhooks/b/notas_fiscais
Observação importante: Os webhooks de A vão disparar para ambos os sistemas (B e C). O filtro de depósito (DROPSHIPPING_DEPOSIT_ID) vai garantir que cada sistema só processe os pedidos do depósito certo. Certifique-se de que A usa depósitos diferentes para B e C.
